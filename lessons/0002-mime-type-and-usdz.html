Lesson 0002

MIME type is the label. USDZ is the package.

Your win for this lesson: you will know why a bad Content-Type can stop Safari AR before any AR rendering happens.

The package-label picture

USDZ file The package: a 3D scene that Apple AR Quick Look can open.
MIME type The shipping label: model/vnd.usdz+zip.
AR Quick Look The native Apple viewer that handles the AR placement.

MIME type

A MIME type is a label sent by the server in an HTTP response. It tells the browser what kind of thing it just received.

Examples:

  • image/png means PNG image.
  • text/html means HTML page.
  • model/vnd.usdz+zip means USDZ 3D model package.

USDZ

USDZ is the Apple-friendly 3D package format used by AR Quick Look. In this project, the USDZ is not the poster image. It is the real AR object: a flat 3D wall-print plane with the artwork texture and physical dimensions.

So if the selected print is 1.524 meters wide and 1.27 meters tall, the USDZ should describe a 3D plane at that size.

How it relates to rendering

MIME type does not render AR

It helps Safari choose the right handler. If the label is wrong, Safari may treat the file like a generic download instead of AR content.

USDZ is what gets rendered

AR Quick Look opens the USDZ, reads the model and texture inside, then uses ARKit underneath to place it on a wall or other surface.

Preview Picture code map

In this repo, the expected labels live in lib/ar-launcher.ts:

usdz: "model/vnd.usdz+zip"

The checked-in asset headers are configured in next.config.ts, so /ar/*.usdz is served with that label.
