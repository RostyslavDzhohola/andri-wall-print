# Teaching Notes

- The user is a visual learner. Prefer diagrams, small flowcharts, and concrete project file maps when a concept is abstract.
- Keep AR lessons grounded in Preview Picture's actual customer flow: admin creates a preview, customer opens the public link, customer taps `Place on wall` in iPhone Safari.
- Distinguish clearly between browser-owned UI, `model-viewer` helper behavior, native AR Quick Look, and native iOS ARKit app development.
