AR File Types and MIME Types

MIME type is the label. USDZ is the file package. AR Quick Look is the native viewer that opens that package.

1. Link <a rel="ar" href="print.usdz">
2. File print.usdz contains the 3D wall-print scene.
3. Label Content-Type: model/vnd.usdz+zip
4. Viewer Safari sends the file to AR Quick Look.

Definitions

MIME type

A short label in an HTTP response that tells the browser what kind of file came back. It does not render AR by itself.

Example: model/vnd.usdz+zip means "this response is a USDZ model package."

USDZ

A single Apple-friendly package for a 3D scene and its assets. In Preview Picture, the USDZ represents the wall print as a real-size flat 3D plane with the artwork image on it.

Why MIME Type Affects AR

Safari has to decide what to do with a URL. The same URL could be an image, PDF, video, download, or 3D AR model. The MIME type is one of the signals Safari uses to pick the correct handler.

If Safari sees... It can infer... Likely outcome
rel="ar" + .usdz URL + model/vnd.usdz+zip This is AR Quick Look content. Open native AR viewer.
.usdz file served as application/octet-stream This might be unknown binary data. Download or fail to launch AR.
Correct MIME type but broken/empty file The label says USDZ, but the package is invalid. Quick Look may open blank, error, or fail.
