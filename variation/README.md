# Design variation prototypes

This folder contains ten static design prototypes for the Preview Picture / Wall Print Pro project.

Open any `index.html` directly in a browser. No local app server is required.

## Codex-authored

- `codex/version-one/index.html` - calibrated room preview.
- `codex/version-two/index.html` - seller dispatch board.
- `codex/version-three/index.html` - mobile client handoff.
- `codex/version-four/index.html` - architect elevation proof.
- `codex/version-five/index.html` - conversion showroom.

## Cursor-authored
