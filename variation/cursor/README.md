# Cursor Prototypes

Five UI concepts for the Wall Print Pro gallery/AR preview experience.

---

## version-one/index.html
**Minimal Gallery** - Light warm theme with sticky sidebar layout. Thumbnail carousel below the main preview. Fixed bottom action bar with AR button. Mobile-first responsive with collapsible nav.

## version-two/index.html
**Studio Darkroom** - Dark theme with coral accent. Sidebar artwork list with user avatar. Grid-based wall preview with measurement overlay. Info panel with four-column spec grid. Scale-in animation on artwork switch.

## version-three/index.html
**Editorial** - Magazine-style layout with serif typography. Split-screen: text panel with pull quote styling, visual panel with carousel navigation. Warm paper palette with copper accent. Horizontal dot navigation.

## version-four/index.html
**Print Studio Proofing Table** - Workshop metaphor with wood textures and craft paper tones. Job ticket header with status badge. Proof sheet with corner crop marks. Measurement strip with ruler scale. Thumbnail strip labeled Front/Detail/Color/Texture.

## version-five/index.html
**Night Installation Preview** - Architectural dark palette for evening context. Ambient wall surface with radial glow lighting. Materials palette sidebar (Fabric Matte, Vinyl Gloss, Canvas Texture). Venue header with time indicator and install badge. Confident amber CTA for AR.
